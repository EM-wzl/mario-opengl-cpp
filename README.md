# OpenGL 版超级马里奥

C++17 / OpenGL 3.3 Core / GLFW / GLM 的横版卷轴 RPG 化平台游戏。角色、地块、背景、ASCII 位图字体均在启动时由代码生成；中文界面由 Windows 系统字体在运行时光栅化为动态字形图集；音效为实时合成 PCM。工程不依赖外部图片、模型或音频文件，游戏运行时不联网。

OpenGL 函数加载由 `src/glcore.{h,cpp}` 完成，不依赖 GLEW/GLAD。仓库内置 GLFW 与 GLM，克隆后默认即可离线构建。

GitHub 仓库：https://github.com/EM-wzl/mario-opengl-cpp

## 构建

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
```

产物：`build/bin/mario`（Windows 为 `build/bin/mario.exe`）。

其他依赖方式：

- 联网拉取：`-DMARIO_FETCH_DEPS=ON`
- 系统依赖：Linux 安装 `libglfw3-dev libglm-dev libgl1-mesa-dev libasound2-dev`
- 指定本地依赖：`-DMARIO_LOCAL_GLFW_DIR=... -DMARIO_LOCAL_GLM_DIR=...`

### Windows 中文路径

中文工程路径会让 Ninja 的依赖扫描失败。用 `subst` 映射英文盘符：

```bat
subst X: D:\cpp\马里奥
cmake -S X:\ -B X:\build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build X:\build -j
```

Windows 下 CMake 会自动把内置依赖复制到英文临时目录，避免头文件路径带中文。

## 操作与界面

游戏内全部界面已汉化，中英文混排均可正常显示。

- `A/D` 或 `←/→`：移动；`Shift/X`：加速
- `Space/W/↑`：跳跃，长按高跳、短按小跳
- `J`：武器攻击；`Q`：切换已拥有武器
- `F` 或 `E`：与商店、箱子交互
- `C / Z / V`：角色主动技能
- `F5`：保存当前存档位；`F9` 或 `L`：读取当前存档位
- `P/Esc`：暂停；`M`：静音；`Enter`：开始、确认、购买、继续

标题界面用 `↑/↓` 或 `W/S` 选择行，`←/→` 或 `A/D` 修改值：模式、角色、剧情起始关或无尽难度、随机种子、存档位。`L` 可直接读取选中存档位，`Enter` 开始新游戏。

## 100 血与战斗规则

- 角色初始 **100 点体力**，上限可通过天赋或商店训练提升到 200。
- **碰到怪物不再扣血**。伤害只来自可见的敌人近战判定、远程投射物、Boss 攻击或落坑。
- 普通敌人分工：
  - 栗宝宝、乌龟、刺刺龟：近距离挥击/突刺，出现短暂红色近战判定框。
  - 飞行乌龟、食人花：发射远程弹。
  - Boss：吐蛋、火焰连发或冲锋。
- 受伤后短暂无敌；体力归零才 Game Over。
- 绿蘑菇、药水、箱子与商店都能恢复体力；金币现在是商店货币，不再自动兑换体力。

## 武器系统

| 武器 | 类型 | 基础伤害 | 冷却 | 获取 |
| --- | --- | --- | --- | --- |
| 拳头 | 近战 | 6 | 0.35s | 初始拥有 |
| 木剑 | 近战 | 18 | 0.45s | 商店购买 / 箱子 |
| 短弓 | 远程 | 14 | 0.55s | 商店购买 / 箱子 |
| 火杖 | 远程 | 22 | 0.70s | 商店购买 / 箱子 |

- 武器可强化到 9 级，每级增加伤害。
- 近战武器在角色前方生成攻击框；远程武器发射可被地形阻挡的玩家投射物。
- 武器、等级、当前装备都会写入存档。
- HUD 显示当前武器、等级与冷却状态。

## 商店与箱子

- 每个剧情关和无尽区域至少 1 个商店、2 个箱子；靠近后按 `F` 交互。
- 商店可购买木剑、短弓、火杖、武器强化、药水和体力训练。
- 箱子可开出金币、体力、武器或武器强化；开启状态在本次关卡内保留，并会触发自动存档。
- 商店界面用 `←/→` 选择、`Enter` 购买、`F` 或 `P` 离开。

## 成长、怪物等级与天赋

- 消灭怪物与 Boss 获得经验；升级后弹出三个天赋选项，用 `←/→` 选择、`Enter` 确认。
- 天赋包括移速、跳跃、经验、分数、火球冷却、技能冷却、金币磁吸、体力上限、踩踏反弹，可叠加并写入存档。
- 怪物显示 `Lx` 等级：生命、攻击伤害、速度、得分与经验随等级提升；受伤闪红并显示血条。
- 剧情后期、无尽深层和玩家等级提升都会继续推高怪物等级。

## 剧情关卡、无限世界与 Boss

八关剧情：绿丘、管道之路、弹簧峡谷、移动要塞、天空之桥、最终试炼、齿轮洞窟、星夜登峰。

无限世界由「层数 + 种子 + 难度」确定性生成，包含坑洞、云桥、移动平台、弹簧、砖块、问号块、金币、管道、商店、箱子、五类普通敌人和轮换 Boss。触碰旗杆后进入下一层，没有终点；成长、分数与体力持续继承。

三类 Boss：

- **爆爆**：冲锋与跳跃，半血后加速。
- **鸟姐**：小跳并吐出弹跳蛋弹。
- **库巴**：慢走、跳跃并连续喷射火焰。

Boss 有独立名称、大体型、血条与多段血量；半血后进入狂暴阶段。Boss 存活时旗杆锁定，必须击败首领才能过关。

## 存档

- 三档本地存档：`.mario_save_1.dat`、`.mario_save_2.dat`、`.mario_save_3.dat`。
- 存档版本 2，包含模式、角色、难度、种子、关卡/层数、分数、金币、100 血体力、等级、经验、形态、检查点、剩余时间、天赋、武器拥有状态、武器等级与当前装备。
- 自动保存：开局、检查点、受伤、天赋确认、购买、开箱、过关与无尽进层。
- 旧版本 1 存档会自动按 20 倍迁移到 100 血制。

## 启动与自动验证

直接双击 `mario.exe` 时不会停留在命令行窗口：程序启动时把控制台输出切到 UTF-8，并在确认控制台只属于自己时自动隐藏它、把游戏窗口置于前台。从已有终端运行则保留终端输出，中文不会变成乱码。

```bash
./build/bin/mario --validate          # 校验剧情关、生成关、Boss、商店与箱子布置
./build/bin/mario --smoke             # 隐藏窗口逐关更新/绘制，并验证菜单、技能、升级、存档、武器、商店、箱子、敌人攻击、Boss、无尽推进
./build/bin/mario --capture 前缀       # 抓取标题界面与关卡画面的 BMP，便于无截屏环境下检查实际渲染
```

`--capture` 会生成 `前缀_title.bmp` 与 `前缀_level.bmp`。前两者返回 0 表示通过。

## 扩展

- 新增剧情关：在 `src/level.cpp` 的 `makeLevelDefinition` 返回新 `LevelDef`，同步 `config::levelCount`。
- 新增无限世界规则：修改 `makeEndlessLevelDefinition`。
- 新增武器：在 `WeaponType` 与 `src/progression.cpp` 的数值表登记，并在商店/箱子逻辑中接入。
- 新增天赋：在 `src/progression.h/.cpp` 登记，在 `Game::applyTalent` 添加效果。
- 新增敌人或 Boss：继承 `Enemy`，在 `EnemySpawnType` / `BossType` 与 `Game::loadLevel` 注册。
- 新增存档字段：扩展 `Game::SaveData` 与 `saveGame` / `readSave`，保持 `version` 兼容。
