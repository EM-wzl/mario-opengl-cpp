# OpenGL 版超级马里奥

C++17 / OpenGL 3.3 Core / GLFW / GLM 的横版卷轴平台游戏。角色、地块、背景、ASCII 位图字体均在启动时由代码生成；中文界面由 Windows 系统字体在运行时光栅化为动态字形图集；音效为实时合成 PCM。工程不依赖外部图片、模型或音频文件，游戏运行时不联网。

OpenGL 函数加载由 `src/glcore.{h,cpp}` 完成，不依赖 GLEW/GLAD。仓库内置 GLFW 与 GLM，克隆后默认即可离线构建。

GitHub 仓库：https://github.com/EM-wzl/mario-opengl-cpp

## 构建

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
```

产物：`build/bin/mario`（Windows 为 `build/bin/mario.exe`）。

其他依赖方式：

- 联网拉取：`-DMARIO_FETCH_DEPS=ON`
- 系统依赖：Linux 安装 `libglfw3-dev libglm-dev libgl1-mesa-dev libasound2-dev`
- 指定本地依赖：`-DMARIO_LOCAL_GLFW_DIR=... -DMARIO_LOCAL_GLM_DIR=...`

### Windows 中文路径

中文工程路径会让 Ninja 的依赖扫描失败。用 `subst` 映射英文盘符：

```bat
subst X: D:\cpp\马里奥
cmake -S X:\ -B X:\build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build X:\build -j
```

Windows 下 CMake 会自动把内置依赖复制到英文临时目录，避免头文件路径带中文。

## 操作与界面

游戏内全部界面已汉化，中英文混排均可正常显示。

- `A/D` 或 `←/→`：移动；`Shift/X`：加速
- `Space/W/↑`：跳跃，长按高跳、短按小跳
- 火焰形态按 `X` 或 `Shift`：发射火球
- `C / Z / V`：角色主动技能
- `F5`：保存当前存档位；`F9` 或 `L`：读取当前存档位
- `P/Esc`：暂停；`M`：静音；`Enter`：开始、确认天赋、继续

标题界面用 `↑/↓` 或 `W/S` 选择行，`←/→` 或 `A/D` 修改值：

- 模式：剧情 / 无尽
- 角色：马力欧、路易吉、奇诺比奥、碧姬
- 剧情起始关 / 无尽难度
- 随机种子
- 存档位 1 / 2 / 3（显示等级与体力摘要）

`L` 可直接读取选中存档位，`Enter` 开始新游戏。

## 体力系统

游戏采用 **HP 血量**，不再使用一条一条的生命：

- 初始 5 点体力，上限可通过天赋提升到 9 点。
- 碰到敌人、Boss 投射物会损失 1 点体力，并短暂无敌、形态降一级。
- 掉入坑洞损失 1 点体力并在检查点或关卡起点重生；体力归零才进入 Game Over。
- 绿蘑菇、100 枚金币可恢复 1 点体力；「额外体力」天赋提升上限并恢复 1 点。
- HUD 显示 `体力 X/Y` 与红色心形格。

## 存档

- 三档本地存档，路径为用户目录下的 `.mario_save_1.dat`、`.mario_save_2.dat`、`.mario_save_3.dat`。
- 自动保存：开局、检查点、受伤、天赋确认、过关进入下一关、无尽进入下一层。
- 手动保存/读取：`F5` / `F9` 或 `L`；标题界面显示各档摘要与读取提示。
- 保存内容：模式、角色、难度、种子、当前关卡/层数、分数、金币、体力、等级、经验、形态、检查点、剩余时间和全部天赋。

## 角色与技能

| 角色 | 被动 | 主动技能 |
| --- | --- | --- |
| 马力欧 | 均衡手感 | 护盾：短暂无敌 |
| 路易吉 | 跳跃更高 | 二段跳：空中额外跳一次 |
| 奇诺比奥 | 移动更快 | 冲刺：短距高速冲刺 |
| 碧姬 | 长按跳跃重力更低 | 星之庇护：短时星之力 |

## 成长、怪物等级与天赋

- 消灭怪物与 Boss 获得经验；升级后弹出三个天赋选项，用 `←/→` 选择、`Enter` 确认。
- 天赋包括移速、跳跃、经验、分数、火球冷却、技能冷却、金币磁吸、体力上限、踩踏反弹，可叠加并写入存档。
- 怪物显示 `Lx` 等级：每 3 级增加 1 点生命，并提升速度、分数与经验；受伤闪红并显示血条。
- 剧情后期、无尽深层和玩家等级提升都会继续推高怪物等级。

## 剧情关卡与无限世界

八关剧情：

| 关卡 | 名称 | 主要挑战 |
| --- | --- | --- |
| 1-1 | 绿丘 | 金币、栗宝宝、问号块、管道、坑洞 |
| 1-2 | 管道之路 | 乌龟与食人花、滑壳连锁 |
| 1-3 | 弹簧峡谷 | 弹簧、单向云平台、飞行乌龟、刺刺龟 |
| 1-4 | 移动要塞 | 移动平台、首领「爆爆」 |
| 2-1 | 天空之桥 | 空中路线、云桥与移动平台 |
| 2-2 | 最终试炼 | 综合机制、首领「鸟姐」 |
| 2-3 | 齿轮洞窟 | 连续移动平台与高等级混合敌人 |
| 2-4 | 星夜登峰 | 夜空终章、首领「库巴」 |

无限世界由「层数 + 种子 + 难度」确定性生成，包含坑洞、云桥、移动平台、弹簧、砖块、问号块、金币、管道、五类普通敌人和轮换 Boss。触碰旗杆后进入下一层，没有终点；成长、分数与体力持续继承。

## Boss

- **爆爆**：冲锋与跳跃，半血后加速。
- **鸟姐**：小跳并吐出弹跳蛋弹。
- **库巴**：慢走、跳跃并连续喷射火焰。
- Boss 有独立名称、大体型、血条与多段血量；半血后进入狂暴阶段。
- Boss 存活时旗杆锁定，必须击败首领才能过关；击败后自动存档。
- 可被踩踏、火球、滑壳与无敌星伤害，并额外奖励分数与经验。

## 自动验证

```bash
./build/bin/mario --validate   # 校验剧情关、生成关、Boss 放置与存档数据
./build/bin/mario --smoke      # 隐藏窗口逐关更新/绘制，并验证菜单、技能、升级、存档、Boss、无尽推进
```

两者返回 0 表示通过。

## 扩展

- 新增剧情关：在 `src/level.cpp` 的 `makeLevelDefinition` 返回新 `LevelDef`，同步 `config::levelCount`。
- 新增无限世界规则：修改 `makeEndlessLevelDefinition`。
- 新增天赋：在 `src/progression.h/.cpp` 登记，在 `Game::applyTalent` 添加效果。
- 新增角色技能：在 `CharacterType` 与 `Player::useSkill` 添加分支。
- 新增敌人或 Boss：继承 `Enemy`，在 `EnemySpawnType` / `BossType` 与 `Game::loadLevel` 注册。
- 新增存档字段：扩展 `Game::SaveData` 与 `saveGame` / `readSave`，保持 `version` 兼容。
